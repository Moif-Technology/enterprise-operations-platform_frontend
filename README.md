# Enterprise Operations Platform Frontend

Frontend starter for the Enterprise Operations Platform.

## First Priority

Build the design system and app foundation first. Do not start full module screens until the shared shell, navigation, buttons, badges, tables, forms, and states are stable.

## Run

```bash
pnpm install
pnpm dev
```

Open:

```text
http://localhost:3000
```

## Developer Handoff

Read in this order:

1. `docs/FRONTEND_DEVELOPER_SPLIT.md`
2. `docs/DESIGN_SYSTEM.md`
3. `docs/MODULE_01_FOUNDATION.md`

## Current Scope

- Frontend only.
- Backend APIs are not required for Module 01.
- Use placeholder/sample data until backend modules are ready.
