# Swetha - Module 02 Operations Core

## Goal

Build the main service operations flow: Service Requests to Work Orders to Supervisor Verification.

## Pages

- Operations Dashboard
- Service Request List
- Create Service Request
- Service Request Detail
- Classification Queue
- Work Order List
- Work Order Detail
- Work Order Checklist
- Supervisor Verification Queue

## User Roles

- Operations Manager
- Supervisor
- Dispatcher
- Facility Manager

## Required UX

- Clear status on every record.
- Simple filters for priority, SLA, status, customer, site, and technician.
- One primary action per page.
- Request and work order pages must feel connected.
- Use sample data until backend APIs are ready.

## Acceptance

- A user can follow a request from creation to work order.
- Work order detail shows customer, site, asset, SLA, technician, checklist, notes, and status.
- Supervisor verification queue clearly shows jobs needing approval.
