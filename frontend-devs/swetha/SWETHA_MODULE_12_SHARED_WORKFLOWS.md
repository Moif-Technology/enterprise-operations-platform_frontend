# Swetha - Module 12 Shared Workflows

## Goal

Support shared operational workflows that appear across modules.

## Pages And Patterns

- Approval inbox support for operations records
- Activity timeline pattern
- Status transition pattern
- Notification center usage in operations pages
- Document/photo section in work order pages

## User Roles

- Operations Manager
- Supervisor
- Dispatcher
- Facility Manager

## Required UX

- Every approval/status change should be understandable.
- Timelines should show business activity, not technical logs.
- Notifications should guide users to action.

## Acceptance

- Work orders and service requests use the same activity/status patterns as other modules.
- Shared workflow patterns are reusable.
