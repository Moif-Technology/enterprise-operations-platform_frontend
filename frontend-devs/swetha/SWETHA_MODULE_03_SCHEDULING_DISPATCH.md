# Swetha - Module 03 Scheduling and Dispatch

## Goal

Build the dispatch experience for assigning jobs and managing technician workload.

## Pages

- Dispatch Board
- Technician Calendar
- Job Assignment Panel
- Reschedule Flow
- Technician Workload View
- SLA Risk View

## User Roles

- Dispatcher
- Supervisor
- Operations Manager

## Required UX

- Show unassigned jobs clearly.
- Show technician availability simply.
- Highlight urgent, emergency, and SLA-risk jobs.
- Keep assignment fast and low-click.
- Do not create a complex map-first interface yet.

## Acceptance

- Dispatcher can identify which jobs need assignment.
- Dispatcher can understand technician workload at a glance.
- SLA risk is visible without making the page noisy.
