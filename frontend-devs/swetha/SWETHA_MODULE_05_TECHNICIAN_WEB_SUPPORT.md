# Swetha - Module 05 Technician Web Support

## Goal

Prepare web-side technician support screens used by supervisors and dispatchers. The mobile app itself is separate, but web users still need technician visibility.

## Pages

- Technician List
- Technician Detail
- Technician Current Jobs
- Technician Availability
- Technician Performance Snapshot
- Technician Stock Link Placeholder

## User Roles

- Supervisor
- Dispatcher
- Operations Manager

## Required UX

- Show current workload, availability, skill/category, and job history.
- Keep performance simple and operational.
- Link technician data to dispatch and work orders.

## Acceptance

- Supervisor can see technician availability and assigned jobs.
- Dispatcher can use technician information for assignment decisions.
