# Arshidha - Module 07 Inventory and Spare Parts

## Goal

Build spare parts and stock management frontend screens.

## Pages

- Item List
- Item Detail
- Stock Overview
- Warehouse Stock
- Technician Stock
- Stock Movement
- Issue Parts
- Return Parts
- Adjustment
- Low Stock and Reorder

## User Roles

- Inventory Staff
- Store Staff
- Technician
- Operations Manager

## Required UX

- Stock levels must be easy to scan.
- Every movement must show a reason.
- Parts usage must connect to work orders.
- Keep forms short and practical.

## Acceptance

- User can see item availability by warehouse and technician.
- User can understand issue, return, adjustment, and reorder flows.
