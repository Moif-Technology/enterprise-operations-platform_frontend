# Arshidha - Module 11 Settings and Platform Admin

## Goal

Build company settings and separate platform admin frontend screens.

## Pages

- Company Settings
- Branch Settings
- Users
- Roles
- Permissions
- Categories
- Statuses
- Priorities
- SLA Configuration
- Notification Settings
- Workflow Settings
- Templates
- Integrations
- AI Settings
- Platform Tenants
- Subscription Plans
- Feature Access
- Usage
- Support Overview

## User Roles

- Company Admin
- Platform Super Admin

## Required UX

- Platform admin must feel separate from company user screens.
- Settings should be grouped and searchable.
- Avoid showing advanced technical settings to everyday users.

## Acceptance

- Company settings and platform admin are clearly separated.
- Admin users can understand where configuration belongs.
