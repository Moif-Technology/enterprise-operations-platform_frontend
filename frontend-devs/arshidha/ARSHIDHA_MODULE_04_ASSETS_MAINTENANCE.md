# Arshidha - Module 04 Assets and Preventive Maintenance

## Goal

Build the asset management and preventive maintenance frontend.

## Pages

- Asset List
- Register Asset
- Asset Detail
- Asset Service History
- Asset Documents
- Maintenance Plans
- Maintenance Calendar
- Upcoming Maintenance
- Preventive Maintenance Work Order Flow

## User Roles

- Facility Manager
- Supervisor
- Operations Manager
- Technician

## Required UX

- Asset detail should show the full asset story.
- Maintenance planning should be simple and repeatable.
- QR identity should be visible as a placeholder.
- Use the shared list/detail/form patterns.

## Acceptance

- User can understand asset status, customer/site, service history, and next maintenance due date.
- Maintenance pages connect naturally to work orders.
