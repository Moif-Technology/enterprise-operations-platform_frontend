# Arshidha - Module 08 Procurement

## Goal

Build purchasing workflow screens.

## Pages

- Purchase Request List
- Purchase Request Detail
- Approval View
- RFQ
- Supplier Quotation Comparison
- Purchase Order List
- Purchase Order Detail
- Receiving

## User Roles

- Procurement Staff
- Inventory Staff
- Manager
- Finance Staff

## Required UX

- Approval screens must be clear.
- Supplier comparison should be simple.
- Receiving should show ordered, received, pending, and rejected quantities.
- Procurement should connect to inventory.

## Acceptance

- User can follow purchase request to purchase order to receiving.
- Screens use the same list/detail/form patterns as inventory.
