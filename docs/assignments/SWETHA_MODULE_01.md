## Task Title

## Goal

Build the operational foundation of the frontend: app shell, navigation, top bar, page layout, and operation-focused placeholder screens.

Do not start full business module development yet. First complete the reusable foundation needed for Service Requests, Work Orders, Dispatch, and Operations Dashboard.

## Setup

```bash
git clone https://github.com/Moif-Technology/enterprise-operations-platform_frontend.git
cd enterprise-operations-platform_frontend
pnpm install
pnpm dev
```

Open:

```text
http://localhost:3000
```

- Improve the main app shell.
- Build grouped sidebar navigation.
- Build top bar with global search placeholder.
- Add notification placeholder.
- Add user profile placeholder.
- Create reusable page header pattern.
- Create operations dashboard placeholder.
- Create service request placeholder page or section.
- Create work order placeholder page or section.
- Create dispatch placeholder page or section.
- Add status badge usage in operations screens.
- Add workflow timeline pattern for request to work order journey.

## Important Rules

- Use placeholder/sample data only.
- Do not connect backend APIs yet.
- Do not implement real login/authentication yet.
- Do not create new visual styles outside the design system.
- Keep the UI clean, simple, professional, and enterprise-ready.
- Service Requests and Work Orders should feel like one connected workflow.
