# Arshidha - Module 01 Assignment

## Task Title

Frontend Module 01 - Design System, Shared Components, and Support Foundation

## GitHub Repo

https://github.com/Moif-Technology/enterprise-operations-platform_frontend.git

## Goal

Build the shared design system and reusable UI components that all frontend modules will use.

Do not start full business module development yet. First complete reusable components, states, and patterns so later screens remain consistent.

## Setup

```bash
git clone https://github.com/Moif-Technology/enterprise-operations-platform_frontend.git
cd enterprise-operations-platform_frontend
pnpm install
pnpm dev
```

Open:

```text
http://localhost:3000
```

## Work Scope

- Improve the design system preview.
- Create reusable button component.
- Create reusable badge component.
- Create reusable panel/card pattern.
- Create reusable page header component.
- Create reusable table/list shell.
- Create reusable form field pattern.
- Create search input pattern.
- Create filter bar pattern.
- Create empty state component.
- Create loading state/skeleton component.
- Create error state component.
- Create success state component.
- Create AI suggestion panel component.
- Create asset placeholder section or page.

## Important Rules

- Use placeholder/sample data only.
- Do not connect backend APIs yet.
- Do not create full Assets, Inventory, Finance, or Reports modules yet.
- Do not create a separate style for each module.
- Avoid unnecessary animations and decorative UI.
- Keep forms short and practical.
- AI should appear as a suggestion pattern, not only as a chatbot page.

## Acceptance Criteria

- Frontend runs successfully with `pnpm dev`.
- Design system preview is clear.
- Shared components are reusable for Module 02.
- Empty/loading/error/success states exist.
- AI suggestion panel pattern exists.
- Asset placeholder is present.
- UI follows the enterprise-simple design direction.
- Type check passes.
