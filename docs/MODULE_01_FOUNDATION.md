# Module 01 - Frontend Foundation and Design System

## Goal

Create the shared UI foundation before building business modules.

## Scope

- App shell
- Sidebar navigation
- Top bar
- Dashboard placeholder
- Design system preview
- Shared button pattern
- Shared badge pattern
- Shared panel/card pattern
- Shared list/table pattern
- Shared form pattern
- Empty/loading/error/success states
- AI suggestion panel pattern

## Not Included

- Real authentication
- Backend integration
- Database work
- Full service request screens
- Full work order screens
- Mobile app screens

## Acceptance Criteria

- `pnpm dev` runs inside `frontend`.
- Home screen shows app shell and module overview.
- Design system preview is visible.
- Components are reusable for Module 02.
- UI remains clean, professional, and simple.
